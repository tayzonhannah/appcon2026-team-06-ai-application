# Team 06 — Next.js Application Root

This subfolder contains the core Next.js application codebase for the Conscious Future AI Parenting platform.

## Quick Commands

- `npm run dev`: Starts local development server on `http://localhost:3000`
- `npm run build`: Compiles production build
- `npm run start`: Runs production server

## Important Vercel Setting
Ensure **Root Directory** in Vercel settings is configured to `team-06`.
